# Security policy

## Supported versions

The latest `0.1.x` release receives security fixes. The `main` branch is under active development
and is not a supported release channel.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use GitHub's private
vulnerability reporting for this repository when available, or contact the maintainer
[@JiahuiXu1999](https://github.com/JiahuiXu1999) privately through GitHub. Include reproduction
steps, affected versions, impact, and any known mitigation. You should receive an acknowledgement
within seven days.
